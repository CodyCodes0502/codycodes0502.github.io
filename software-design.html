Project Narrative

Designing a More Complete Inventory Experience

Artifact Overview

The artifact that I have chose to display my skills in software design and engineering is my Android application that I created for CS-360. It is an inventory tracking app, designed to allow users to keep track of a wide range of various inventories, such as their refrigerator, a pantry, or even a collection. Users can track multiple inventories through the application, with the ability to edit or delete those inventories or items as needed.

Why I Selected This Artifact

I selected this item as the entire application was created and designed by me, as opposed to other assignments we were given, were we had base code supplied, then we made changes or improvements. This code was all mine, and it was an idea that I wanted to create even before I was enrolled in the class.

The Enhancement

As an improvement to the application, I added an option when adding a new item to be able to simply scan the items barcode in order to add it, as opposed to adding it manually.

Future Updates

I still have further updates that I want to do in order to improve the application. Improving the database systems such as hashing the passwords as opposed to storing them as is, and even more improvements to the scanning feature to make it more user-friendly.

Challenges and Reflection

This process of improving the application was a bit of a challenge, as I had to re-learn how to use android studio again, as it has been a bit since my original class where this artifact was created. One thing that I did learn during this process was how to implements googles barcode scanning service, which is an API that I have not worked with in the past, but turned out to be relatively simple to use.
