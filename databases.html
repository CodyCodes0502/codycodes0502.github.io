Project Narrative

Designing a More Complete Inventory Experience

Artifact Overview

This artifact is an inventory tracking app that I created for CS-360. It is designed as a universal inventory tracker allowing you to add multiple various ‘inventories’ and tracking the items in each one, tracked using SQLite databases.

Why I Selected This Artifact

This was included in my ePortfolio as the data tracked by the app uses databases and demonstrates my ability to design and implement databases with appropriate relationships.

The Enhancement

The artifact was improved by improving on the relationships of the databases, and customizing the database shown in the UI dependent on the user that created it, adding a level of privacy to the database contents.

Reflection and Challenges

This process was a bit of a challenge as database work was a bit of a struggle at the time I created this application initially. However, once I started working on it, it all started making a bit more sense.
